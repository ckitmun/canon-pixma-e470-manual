# Canon PIXMA E470 Illustrated Digital User Guide

This is an independent multilingual quick-reference guide for the Canon PIXMA E470 family.

## Publish / update with GitHub Pages
1. Open the repository `ckitmun/canon-pixma-e470-manual`.
2. Open `index.html` and choose the pencil (Edit) icon, or use **Add file → Upload files**.
3. Replace the existing `index.html` with the updated `index.html` from this package.
4. Commit the change to the `main` branch. GitHub Pages will redeploy automatically.

The published URL stays the same: https://ckitmun.github.io/canon-pixma-e470-manual/

## Images and attribution
The product-operation diagrams embedded in the guide are loaded from Canon's official E470 series Online Manual and are credited to Canon Inc. They require an internet connection to display.
