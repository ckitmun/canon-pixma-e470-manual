# Canon PIXMA E470 Digital Quick Guide

A responsive, multilingual (English / Simplified Chinese / Bahasa Melayu) static website for GitHub Pages.

## Publish with GitHub Pages
1. Sign in to GitHub and create a **public** repository, e.g. `pixma-e470-guide`.
2. Upload `index.html` to the repository root and commit.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**; select `main` and `/ (root)`, then Save.
5. Wait for GitHub Pages to publish. The URL is usually `https://YOUR-USERNAME.github.io/pixma-e470-guide/`.
6. Generate the final QR code using that exact public URL. Do not print a QR code until the published page has been tested on a phone.

## Important
This is an independent quick-reference guide, not an official Canon publication. It uses simplified instructional wording and a schematic illustration. For model-specific procedures, error codes, current drivers and safety details, follow Canon's official documentation linked inside the site.
